## 🧠 Engineering Vision & Problem Formulation

In real-world cyber-physical and autonomous systems—such as **mobile robot fleet localization**, automated manufacturing cells, and fault-tolerant telemetry—sensors rarely provide full state observability. Instead, an observer records a sequence of symbolic events $w = l_1 l_2 \dots l_k \in \Sigma^*$ generated by an unknown initial resource distribution $M_0$, while distinct physical transitions may emit identical sensor signatures ($L(t_i) = L(t_j)$).

> **Core Control-Theory Question:** *Given a partially observed event sequence $w$ in a Labeled Petri Net $N = (P, T, Pre, Post, L)$, how can we reconstruct the Minimal Initial Marking ($M_0 \in \mathbb{N}^{\vert{}P\vert{}}$) required to explain $w$—without succumbing to exponential state-space explosion on large-scale robotic topologies?*

This repository provides a complete, cross-validated algorithmic framework in **Python (NumPy)** and **MATLAB**, progressing from exact backward algebraic inversion to Pareto-front multi-objective pruning and bounded-memory heuristic search.
